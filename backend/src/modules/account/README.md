# Backend / Account

하나의 백엔드 서버 안에서 계정과 사용자 설정을 담당하는 모듈입니다.
담당자는 팀에서 확정한 뒤 이 문서에 기록합니다.

## 담당 범위

- GitHub OAuth 로그인
- 사용자와 프로필
- 사용자 설정
- 계정 관련 DB 설계와 저장·조회
- 공통 DB 스키마 및 마이그레이션 관리에 대한 협의

## 함께 정할 사항

- Platform: 인증된 사용자 식별 정보의 전달 방식과 모듈 간 호출 규칙
- Platform: 공부 세션·접속 상태와 사용자 데이터의 관계, 공통 DB 변경
- 프론트엔드: 로그인 흐름, 로그인 유지 방식, 사용자·프로필·설정 API 규격
- 서버 공통: 인증 실패와 접근 권한 오류 응답 형식

서버 진입점과 환경변수, DB 연결은 `backend/`의 공통 구성을 사용합니다.
이 폴더에 별도의 서버 실행 설정이나 `package.json`을 만들지 않습니다.
