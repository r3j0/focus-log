# Visual / Voyage

하나의 프론트엔드 안에서 메인 화면과 시각적 연출을 담당하는 기능 영역입니다.
담당자는 팀에서 확정한 뒤 이 문서에 기록합니다.

## 담당 범위

- 메인 화면 구성
- 캐릭터와 배경 표현
- 애니메이션
- Pass-by 연출

## 함께 정할 사항

- Focus: 타이머·집중 상태를 화면과 캐릭터 연출에 연결하는 방식
- Platform: 접속 상태와 탐색 결과를 전달받는 API 규격
- Account: 화면에 표시할 사용자·프로필 정보의 API 규격
- 공통 UI와 정적 이미지 등의 저장 위치 및 사용 규칙

컴포넌트와 상태 로직은 구현 시 필요한 단위로 추가합니다.
페이지와 URL 연결은 Next.js 초기화 후 `src/app/`에서 담당합니다.
이 폴더는 독립 앱이나 별도의 workspace 패키지가 아닙니다.
