# Desktop / Focus

집중 활동과 관련된 화면, 사용자 조작, 클라이언트 상태를 담당하는 기능 영역입니다.
담당자는 팀에서 확정한 뒤 이 문서에 기록합니다.

## 담당 범위

- Floating Pet의 화면과 상태
- 집중 타이머
- TODO
- 집중 활동과 관련된 클라이언트 상태

## 함께 정할 사항

- Voyage: 집중 상태와 타이머 상태를 시각적 연출에 연결하는 방식
- Platform: 공부 세션 시작·종료, 기록 저장, 접속 상태의 API 규격
- Account: 로그인 상태와 사용자 설정을 적용하는 방식
- TODO와 타이머 상태 중 로컬에 저장할 값과 서버에 저장할 값

운영체제 위에 별도 창을 띄우는 데스크톱 앱이 필요한지는 실행 환경을 정할 때 결정합니다.
현재 폴더는 기능의 범위를 나타내며, 데스크톱 실행 도구나 별도 앱을 초기화하지 않습니다.
타이머·TODO 등의 하위 폴더는 실제 구현을 시작할 때 추가합니다.
